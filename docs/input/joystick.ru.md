# Джойстик
Джойстик — это небольшой рычаг управления, который можно перемещать пальцами. Он используется в игровых контроллерах и робототехнике для перемещения объектов в разных направлениях. Обычно содержит два потенциометра — один для движения влево-вправо (ось X) и один для движения вверх-вниз (ось Y).

---
### `Joystick(slot)`
Чтобы создать объект Joystick, вызовите `Joystick(slot)`.

Только слот F на PiBody может одновременно обрабатывать два аналоговых сигнала, поэтому на других слотах джойстик будет работать некорректно.

**Аргументы:**

- `slot (string)` — метка слота ("F")

**Возвращает:**
    Возвращает класс ``Joystick`` для *slot*.
```python
from pibody import Joystick

joystick = Joystick("F")
```

---
### `.read() -> (int, int)`
Возвращает нормализованные значения `(x, y)` в **[0, 1.0]**, или **None** для оси, если она недоступна.

```python
x, y = joystick.read()
print(x, y)
```

---
### `.read_x() -> int`
Возвращает нормализованное значение оси X, или **None**, если ось недоступна.

```python
x = joystick.read_x()
print(x)
```

---
### `.read_y() -> int`
Возвращает нормализованное значение оси Y, или **None**, если ось недоступна.

```python
y = joystick.read_y()
print(y)
```

---
## Примеры

```python
from pibody import Joystick

joystick = Joystick("F")

while True:
    x, y = joystick.read()
    # получить ось X
    print(x)

    # получить ось X
    x1 = joystick.read_x()
    print(x1)

    # получить ось X
    x2 = joystick.read()[0]
    print(x2)
```
