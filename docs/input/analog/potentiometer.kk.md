# Потенциометр
Потенциометр (айнымалы резистор) кәдімгі резисторға ұқсас, бірақ оның кедергісін реттеуге болады. Тұтқаны бұру арқылы кедергі мәнін өзгертесіз.

---
### `Potentiometer(slot) -> ADC`
Potentiometer объектісін жасау үшін `Potentiometer(slot)` шақырыңыз.

Сондай-ақ `Pot(slot)` қысқа атауын пайдалануға болады.

Потенциометр аналогты болғандықтан, оны тек АЦП (аналогты-цифрлық түрлендіргіш) бар слоттарға қосуға болады, ал PiBody-де осындай 2 слот бар: `"C"` және `"F"`.

**Аргументтер:**

- `slot (string)` — слот белгісі ("C", "F").

**Қайтарады:**
    *slot* аналогты пины үшін ``ADC`` объектісін қайтарады.

```python
from pibody import Potentiometer

pot = Potentiometer("C")
```

---
### `.read() -> float`
**[0, 1.0]** диапазонындағы мәнді қайтарады.

```python
pot.read()
```

```python
from pibody import Pot  # қысқа атау

pot = Pot("C")

while True:
    print("потенциометр мәні:", pot.read())
```

---
### `.read_u16() -> int`
АЦП өңделмеген мәнін **[0, 65535]** диапазонында оқиды.

```python
data = pot.read_u16()
print(data)
```

---
### `.read_uv() -> int`
Микровольтқа түрлендірілген АЦП мәнін оқиды.

```python
data = pot.read_uv()
print(data)
```

---
### `.deinit()`
АЦП өшіріп, пиноты балама пайдалану үшін босатады.

```python
pot.deinit()
```
