# Потенциометр
Потенциометр (переменный резистор) похож на обычный резистор, но его сопротивление можно регулировать. Поворачивая ручку, вы изменяете величину сопротивления.

---
### `Potentiometer(slot) -> ADC`
Чтобы создать объект Potentiometer, вызовите `Potentiometer(slot)`.

Также можно использовать короткий вызов `Pot(slot)`.

Поскольку потенциометр является аналоговым, его можно подключать только к слотам с АЦП (аналого-цифровым преобразователем), а на PiBody есть только 2 таких слота: `"C"` и `"F"`.

**Аргументы:**

- `slot (string)` — метка слота ("C", "F").

**Возвращает:**
    Возвращает объект ``ADC`` для аналогового пина *slot*.

```python
from pibody import Potentiometer

pot = Potentiometer("C")
```

---
### `.read() -> float`
Возвращает значение в диапазоне **[0, 1.0]**.

```python
pot.read()
```

```python
from pibody import Pot  # короткий вызов

pot = Pot("C")

while True:
    print("значение потенциометра:", pot.read())
```

---
### `.read_u16() -> int`
Читает сырое значение АЦП в диапазоне **[0, 65535]**.

```python
data = pot.read_u16()
print(data)
```

---
### `.read_uv() -> int`
Читает значение АЦП, преобразованное в микровольты.

```python
data = pot.read_uv()
print(data)
```

---
### `.deinit()`
Отключает АЦП и освобождает пин для альтернативного использования.

```python
pot.deinit()
```
