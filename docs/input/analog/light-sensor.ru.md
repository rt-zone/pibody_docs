# Датчик освещённости
Датчик освещённости — это аналоговый датчик, способный измерять уровень падающего на него света.

---
### `LightSensor(slot) -> ADC`
Чтобы создать объект LightSensor, вызовите `LightSensor(slot)`.

Также можно использовать короткий псевдоним `Light(slot)`.

Поскольку датчик освещённости является аналоговым, его можно подключать только к слотам с АЦП (аналого-цифровым преобразователем), а на PiBody есть только 2 таких слота: `"C"` и `"F"`.

**Аргументы:**

- `slot (string)` — метка слота ("C", "F").

**Возвращает:**
    Возвращает объект ``ADC`` для аналогового пина *slot*.

```python
from pibody import LightSensor

light = LightSensor("C")
```

---
### `.read() -> float`
Возвращает значение в диапазоне **[0, 1.0]**.

```python
light.read()
```

```python
from pibody import Light  # короткий псевдоним

light = Light("C")

while True:
    print("значение света:", light.read())
```

---
### `.read_u16() -> int`
Читает сырое значение АЦП в диапазоне **[0, 65535]**.

```python
data = light.read_u16()
print(data)
```

---
### `.read_uv() -> int`
Читает значение АЦП, преобразованное в микровольты.

```python
data = light.read_uv()
print(data)
```

---
### `.deinit()`
Отключает АЦП и освобождает пин для альтернативного использования.

```python
light.deinit()
```
