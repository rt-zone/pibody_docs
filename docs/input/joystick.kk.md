# Джойстик
Джойстик — бұл саусақпен қозғалуға болатын шағын басқару рычагі. Ол ойын контроллерлерінде және робототехникада нысандарды әртүрлі бағытта жылжыту үшін қолданылады. Әдетте, оның құрамында екі потенциометр бар — біреуі солға-оңға қозғалыс үшін (X осі) және біреуі жоғары-төмен қозғалыс үшін (Y осі).

---
### `Joystick(slot)`
Joystick объектісін жасау үшін `Joystick(slot)` шақырыңыз.

PiBody-де тек F слота ғана бір уақытта екі аналогты сигналды өңдей алады, сондықтан басқа слоттарда джойстик дұрыс жұмыс істемейді.

**Аргументтер:**

- `slot (string)` — слот белгісі ("F")

**Қайтарады:**
    *slot* үшін ``Joystick`` объектісін қайтарады.
```python
from pibody import Joystick

joystick = Joystick("F")
```

---
### `.read() -> (int, int)`
Нормаланған `(x, y)` мәндерін **[0, 1.0]** қайтарады, немесе ось қолжетімсіз болса **None**.

```python
x, y = joystick.read()
print(x, y)
```

---
### `.read_x() -> int`
Нормаланған X осінің мәнін қайтарады, немесе ось қолжетімсіз болса **None**.

```python
x = joystick.read_x()
print(x)
```

---
### `.read_y() -> int`
Нормаланған Y осінің мәнін қайтарады, немесе ось қолжетімсіз болса **None**.

```python
y = joystick.read_y()
print(y)
```

---
## Мысалдар

```python
from pibody import Joystick

joystick = Joystick("F")

while True:
    x, y = joystick.read()
    # X осін алу
    print(x)

    # X осін алу
    x1 = joystick.read_x()
    print(x1)

    # X осін алу
    x2 = joystick.read()[0]
    print(x2)
```
