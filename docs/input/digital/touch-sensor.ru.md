# Сенсорный датчик
Сенсорный датчик — это кнопка, которая реагирует на прикосновение пальца или проводящего предмета. В отличие от механических кнопок, он не имеет движущихся частей, что делает его более долговечным и надёжным.

---
### `TouchSensor(slot) -> Pin`
Чтобы создать объект TouchSensor, вызовите `TouchSensor(slot)`.

Также можно использовать короткий вызов `Touch(slot)`.

**Аргументы:**

- `slot (string | int | tuple)` — метка слота ("A", "B", "C", "D", "E", "F", "G", "H"), порт пина (0, 2 и т.д.), кортеж (0, Pin.IN).

**Возвращает:**
    Возвращает цифровой выход ``Pin`` для *slot*.
```python
from pibody import TouchSensor

touch = TouchSensor("A")
```

---
### `.read() -> int`
Возвращает **0 или 1** в зависимости от состояния.

```python
touch.read()
```

```python
from pibody import Touch  # короткий вызов

touch = Touch("A")

while True:
    if touch.read():
        print("Сенсор нажат")
    else:
        print("Сенсор не нажат")
```

---
### `.value() -> int`
То же, что и `.read()`, возвращает **0 или 1** в зависимости от состояния.

```python
value = touch.value()
print(value)
```
