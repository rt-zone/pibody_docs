# Servo 360
Серво 360 (сервопривод непрерывного вращения) крутится свободно, как маленький мотор с редуктором, — из него можно сделать колёса для робота-машинки. В отличие от обычного [серво](servo.md), он не держит угол: тот же сигнал задаёт его **скорость и направление**. Управляется тем же классом `Servo`.

---
## Базовое использование

---
### `Servo(pin) -> Servo`
Чтобы создать объект Servo, вызовите `Servo(pin)`.

**Аргументы:**

- `pin (int)` - порт пина (8 или 9)

**Возвращает:**
    Объект `Servo` для *pin*.

```python
from pibody import Servo

wheel = Servo(8)
```

---
### `.angle(angle | None) -> None | int`
Задаёт скорость и направление вращения через значение угла **(0–180)**.

**Аргументы:**

- `angle (float)` - `90` останавливает серво, `180` — полная скорость в одну сторону, `0` — полная скорость в другую; значения между ними дают меньшую скорость (например, `135` — половина скорости).

Без аргумента возвращает последнее заданное значение, иначе задаёт его и возвращает None.

```python
from pibody import Servo
from time import sleep

wheel = Servo(8)

wheel.angle(180)  # полный ход вперёд
sleep(2)
wheel.angle(90)   # стоп
sleep(1)
wheel.angle(0)    # полный ход назад
sleep(2)
wheel.angle(90)
```

---
### `.off()`
Перестаёт подавать импульсы — серво останавливается. Последнее значение сохраняется: `.angle()` по-прежнему его возвращает.

Серво на пинах **8 и 9 используют один общий блок ШИМ**, поэтому `.off()` на одном из них останавливает оба.

```python
wheel.off()
```

---
### `.on()`
Возобновляет сигнал с последним значением — серво снова крутится с той же скоростью. Новый `.angle()` тоже снова включает выход.

```python
wheel.on()
```
