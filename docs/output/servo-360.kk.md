# Servo 360
Серво 360 (үздіксіз айналатын сервоқозғалтқыш) редукторы бар шағын мотор сияқты еркін айналады — одан робот-машинаның дөңгелектерін жасауға болады. Кәдімгі [сервоқозғалтқыштан](servo.md) айырмашылығы, ол бұрышты ұстап тұрмайды: сол сигнал оның **жылдамдығы мен бағытын** береді. Сол `Servo` класымен басқарылады.

---
## Негізгі қолдану

---
### `Servo(pin) -> Servo`
Servo объектісін жасау үшін `Servo(pin)` шақырыңыз.

**Аргументтер:**

- `pin (int)` - пин порты (8 немесе 9)

**Қайтарады:**
    *pin* үшін `Servo` объектісі.

```python
from pibody import Servo

wheel = Servo(8)
```

---
### `.angle(angle | None) -> None | int`
Айналу жылдамдығы мен бағытын бұрыш мәні арқылы береді **(0–180)**.

**Аргументтер:**

- `angle (float)` - `90` сервоны тоқтатады, `180` — бір бағытта толық жылдамдық, `0` — екінші бағытта толық жылдамдық; арасындағы мәндер азырақ жылдамдық береді (мысалы, `135` — жарты жылдамдық).

Аргументсіз соңғы берілген мәнді қайтарады, әйтпесе оны орнатып, None қайтарады.

```python
from pibody import Servo
from time import sleep

wheel = Servo(8)

wheel.angle(180)  # алға толық жылдамдық
sleep(2)
wheel.angle(90)   # тоқта
sleep(1)
wheel.angle(0)    # артқа толық жылдамдық
sleep(2)
wheel.angle(90)
```

---
### `.off()`
Импульстерді беруді тоқтатады — серво тоқтайды. Соңғы мән сақталады: `.angle()` оны әлі де қайтарады.

**8 және 9** пиндеріндегі серволар **бір ортақ ИЕМ блогын** пайдаланады, сондықтан біреуіндегі `.off()` екеуін де тоқтатады.

```python
wheel.off()
```

---
### `.on()`
Сигналды соңғы мәнмен қайта қосады — серво сол жылдамдықпен қайта айналады. Жаңа `.angle()` те шығысты қайта қосады.

```python
wheel.on()
```
