# Servo
Сервоқозғалтқыш — бұл белгілі бір бұрышқа бұрыла алатын мотор. Кәдімгі мотордан айырмашылығы, ол еркін айнала алмайды (сондықтан одан желдеткіш немесе машина дөңгелегін жасау мүмкін емес), бірақ микроконтроллердің көмегімен серво жетегінің бұрылу бұрышын жарты градус дәлдігімен орнатуға болады, және ол берілген күйді ұстап тұрады.

---
## Негізгі қолдану

---
### `Servo(pin) -> PWM`
Servo объектісін жасау үшін `Servo(pin)` шақырыңыз.

**Аргументтер:**

- `pin (int)` — пин порты (8, 9 немесе 12)

**Қайтарады:**
    *pin* үшін [`pibody.PWM`](pwm.md) шығысын қайтарады.
```python
from pibody import Servo

servo = Servo(9)
```

---
### `.angle(val | None) -> None | int`
Серво бұрышын алу немесе орнату **(0–180 градус)**.

**Аргументтер:**

- `val (float)` — серво бұрышын **[0, 180]** градус диапазонында орнататын опционалды параметр

Аргументсіз шақырғанда ағымдағы бұрышты **[0, 180]** қайтарады, әйтпесе бұрышты орнатып, None қайтарады.

```python
from pibody import Servo
from time import sleep

servo = Servo(8)

servo.angle(180)
sleep(1)

print(servo.angle())  # 180

servo.angle(90)
sleep(1)
servo.angle(0)
sleep(1)

print(servo.angle())  # 0
```

---
### `.on()`
ИЕМ шығысын қайта инициализациялайды (сервоны қосады).

```python
servo.on()
```

---
### `.off()`
ИЕМ шығысын деинициализациялайды (сервоны өшіреді).

```python
servo.off()
```

---
## ИЕМ

Серво орны ИЕМ сигналының **импульс енімен** басқарылады, тікелей толтыру коэффициентімен емес. Мысалы, стандартты 180° серво **0,5 мс** (0°) мен **2,5 мс** (180°) аралығындағы импульсті күтеді, әр **20 мс** сайын қайталанады (50 Гц).

`freq` импульстің қайталану жиілігін орнатады — серво үшін бұл **50 Гц** болуы керек (период = 20 мс). `duty` сигналдың жоғары күйде болатын бөлігін орнатады. Бұрышты duty мәніне түрлендіру:

```
pulse_width = (angle / 180) * 2 + 0.5   # 0,5–2,5 мс
duty = pulse_width / SERVO_PERIOD_MS    # 20 мс бөлігі
```

PiBody жинағында **SERVO_PERIOD_MS = 20** (**1000 // freq** тең).

Ұсынылған диапазоннан **асу** (мысалы, 180° серво үшін импульс > 2,5 мс) сервоға зақым келтірмейді — көптеген модельдер артығын елемей, максималды бұрышта ұстап тұрады. Кейбіреулері механикалық тоқтауда әлсіз гүілдеу шығаруы мүмкін; бұл қалыпты жағдай. **0,5 мс** минималды мәнінен **төмен** мәндер де серво аппаратурасымен 0° күйіне дейін қысылады.

---
### `.duty(value | None) -> None | float`
Бұрышты duty арқылы орнатуға болады. Алдымен бұрышты импульс еніне түрлендіріңіз:
```pulse_width = (angle / 180) * 2 + 0.5```

Осыдан кейін импульс енін толтыру коэффициентіне түрлендіріңіз:
```duty = pulse_width / SERVO_PERIOD_MS```

*int мәндерін пайдаланыңыз* **[0.025, 0.125]** диапазонында.
*Мән* **0** *сервоны өшіреді.*

**Аргументтер:**

- `value (float)` — ИЕМ толтыру коэффициентін орнататын опционалды параметр. **[0, 0.125]** аралығындағы мәнді қабылдайды. Әдепкі: **0**

Егер `value` бос болса, әдіс бұрын пайдаланылған толтыру коэффициентін қайтарады.

```python
from pibody import PWM
SERVO_PERIOD_MS = 20

servo = PWM(8)

angle = 90
pulse_width = (angle / 180) * 2 + 0.5  # 1.5

duty = pulse_width / SERVO_PERIOD_MS   # 0.075
servo.duty(duty)

print(servo.duty())  # 0.075
```

---
### `.duty_u16(value | None) -> None | int`
`.duty()` сияқты, бұрышты duty_u16 арқылы орнатуға болады. **u16** *16-биттік* мәнді білдіреді.

*int мәндерін пайдаланыңыз* **[1638, 8191]** диапазонында
*Мән* **0** *сервоны өшіреді.*

**Аргументтер:**

- `value (int)` — [`pibody.PWM`](pwm.md) толтыру коэффициентін орнататын опционалды параметр. **[8191]** аралығындағы мәнді қабылдайды. Әдепкі: **0**

Егер `value` бос болса, әдіс бұрын пайдаланылған толтыру коэффициентін қайтарады.

```python
from pibody import PWM
SERVO_PERIOD_MS = 20

servo = PWM(8)

angle = 90
pulse_width = (angle / 180) * 2 + 0.5  # 1.5

duty = pulse_width / SERVO_PERIOD_MS   # 0.075 (нормаланған)
duty_u16 = int(duty * 65535)           # ~4915
servo.duty_u16(duty_u16)

print(servo.duty_u16())  # 4915
```

---
### `.freq(value | None) -> None | int`
`freq` импульстің қайталану жиілігін орнатады — серво үшін бұл **50 Гц** болуы керек (период = 20 мс).

**Аргументтер:**

- `value (int)` — ИЕМ жиілігін орнататын опционалды параметр. Әдепкі: **50**

Егер `value` бос болса, әдіс бұрын пайдаланылған жиілікті қайтарады.

```python
pwm.freq(50)

print(pwm.freq())  # 50
```
