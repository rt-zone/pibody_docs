# LED
`pibody.LED()` фабрикалық функциясы сандық шығыс ретінде конфигурацияланған `Pin` объектісін қайтарады. Оны PiBody слотына қосылған жарықдиодты, релені немесе кез келген қосу/өшіру жүктемесін басқару үшін пайдаланыңыз.

---
## Негізгі қолдану

---
### `LED(slot) -> Pin`
LED объектісін жасау үшін `LED(slot)` шақырыңыз.

**Аргументтер:**

- `slot (string | int | tuple)` — слот белгісі ("A", "B", "C", "D", "E", "F", "G", "H"), пин порты (0, 2 және т.б.), кортеж (0, Pin.OUT)

**Қайтарады:**
    *slot* үшін сандық шығыс ``Pin`` қайтарады.
```python
from pibody import LED

led = LED("A")
```

---
### `.on()`
Жалғанған жарықдиодты қосады.
```python
led.on()  # қосу
```

---
### `.off()`
Жалғанған жарықдиодты өшіреді.
```python
led.off()  # өшіру
```

---
### `.value(value | None) -> None | float`
Пин мәнін алу немесе орнату.

**Аргументтер:**

- `value (float)` — күйіне байланысты қосатын немесе өшіретін опционалды параметр: **0 немесе 1**

Аргументсіз шақырғанда ағымдағы күйді **(0 немесе 1)** қайтарады, әйтпесе мәнді орнатып, None қайтарады.

```python
# Қосады, led.on() сияқты
led.value(1)
print(led.value())  # 1

# Өшіреді, led.off() сияқты
led.value(0)
print(led.value())  # 0
```

---
### `.toggle()`
Жарықдиодтың күйін кері өзгертеді.
```python
led.on()            # қосу

led.toggle()        # өшіру

print(led.value())  # 0
```

---
## Басқа функциялар

### `.high()`

Келесі баламалы әдіспен жоғары шығыс деңгейін орнатады:

```python
# led.on() сияқты
led.high()
```

### `.low()`

Келесі баламалы әдіспен төмен шығыс деңгейін орнатады:

```python
# led.off() сияқты
led.low()
```

## ИЕМ (PWM)
Жарықдиод модулін басқару және оның жарықтығын реттеу үшін [`pibody.PWM`](pwm.md) пайдалануға болады — тек қосу/өшіру емес.

Жарықдиод көз көргеннен жылдам қосылып-өшеді. Ми мұны қабылданатын жарықтық деңгейіне орташалайды.

### Параметрлер

- **`freq`** — жарықдиодтың секундына жыпылықтау саны

    - **50 Гц** төмен — көрінетін жыпылықтау (назар аудару эффектілері үшін пайдалы)
    - **100–200 Гц** — негізінен тұрақты, перифериялық көруде жыпылықтауы мүмкін
    - **500–5000 Гц** — адам көзіне толығымен тұрақты көрінеді. **1000 Гц** бастаңыз
    - Жоғары мәндер жақсы, бірақ өзгеше көрінбейді; CPU ресурстарын көбірек пайдаланады

- **`duty`** — әр жыпылықтау кезінде жарықдиодтың қосулы бөлігі (0.0 мен 1.0 аралығында)

    - **0** = толығымен өшірулі
    - **0.25** = күңгірт
    - **0.5** = жарты жарықтық
    - **0.75** = жарық
    - **1.0** = толығымен қосулы (`led.on()` сияқты)

### Негізгі мысал

```python
from pibody import PWM

led = PWM("A")

led.freq(1000)   # 1 кГц — көзге тұрақты
led.duty(0.5)    # жарты жарықтық
```

### Тегіс өшу эффектісі

```python
from pibody import PWM
from time import sleep

led = PWM("A")
led.freq(1000)

while True:
    for i in range(0, 101, 1):       # арттыру
        led.duty(i / 100)
        sleep(0.01)
    for i in range(100, -1, -1):     # азайту
        led.duty(i / 100)
        sleep(0.01)
```
