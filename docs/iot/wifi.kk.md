# WiFi
WiFi модулі PiBody-ді интернетке Wi-Fi арқылы қосады. Мұнда негізгі IoT ақпараттарын (уақыт, ауа райы, валюта бағамы және т.б.) алуға арналған функциялар іске асырылған.

---
## Негізгі қолдану

---
### `WiFi()`
WiFi объектісін жасау үшін `WiFi()` шақырыңыз.

**Қайтарады:**
    ``WiFi`` объектісін қайтарады.
```python
from pibody import WiFi

wifi = WiFi()
```

---
### `.connect(ssid, password, timeout) -> IfConfig`
PiBody-ді интернетке қосады. Әдіс аргументтерінде желі атауы мен парольді көрсетіңіз.

Сәтті қосылу кезінде консольге IP-мекенжайды шығарады.

Егер қазірдің өзінде қосылған болса, ағымдағы конфигурацияны дереу қайтарады.

**Аргументтер:**

- `ssid (string)` — желі атауы
- `password (string)` — желі паролі
- `timeout (int | None)` — опционалды. Қате шығару алдында күту секундтары. Әдепкі: **20 с**

```python
wifi.connect("желі_атауы", "пароль")
```

---
### `.get_time(gmt, formatted) -> string | dict`
Бұл әдіс арқылы интернеттен ағымдағы уақытты білуге болады. Уақыт белдеуін аргумент ретінде көрсетуге болады; алайда әдепкі мән **+5 (Қазақстан уақыты)**.

**Аргументтер:**

- `gmt (int | None)` — уақыт белдеуі. Әдепкі: **+5**
- `formatted (bool | None)` — **True** болса, уақыт деректерімен пішімделген жолды қайтарады

```python
data = wifi.get_time(gmt=5)
print(data)
```

---
### `.get_currency(from_currency, to_currency) -> float`
Валюта бағамын қайтарады. Аргументтерде қай валютадан және қай валютаға түрлендіруді көрсетуге болады. Әдепкі бойынша бағам USD-тен KZT-ге орнатылған.

**Аргументтер:**

- `from_currency (string | None)` — бастапқы валюта коды. Әдепкі: **USD**
- `to_currency (string | None)` — мақсатты валюта коды. Әдепкі: **KZT**

```python
data = wifi.get_currency(from_currency="USD", to_currency="KZT")
print(data)
```

---
### `.get_temperature(city) -> float`
Бұл әдіс ағымдағы сыртқы температураны білуге мүмкіндік береді. Ауа райы температурасын білгіңіз келетін қаланы көрсетуге болады; әдепкі бойынша қала Астана.

**Аргументтер:**

- `city (string | None)` — қала атауы. Әдепкі: **Астана**

```python
data = wifi.get_temperature("Астана")
print(data)
```

---
### `.get_ip_info() -> dict`
Жария IP-мекенжайды және орналасу ақпаратын алады.

```python
data = wifi.get_ip_info()
print(data)
```

---
## Басқа функциялар

---
### `.scan()`
Қолжетімді Wi-Fi желілерінің және олардың RSSI тізімін қайтарады. RSSI — сигнал «күшінің» индексі. Ол теріс сандармен өлшенеді — мән нөлге неғұрлым жақын болса, сигнал соғұрлым күшті деп есептеледі.

**Қайтарады:**
    Әр көрінетін желі үшін ``(ssid, rssi)`` кортеждерінің тізімі.

```python
data = wifi.scan()
print(data)
```

---
### `.is_connected() -> bool`
Интерфейс қазіргі уақытта қосылған болса, **True** қайтарады.

```python
data = wifi.is_connected()
print(data)
```

---
### `.disconnect()`
Ағымдағы Wi-Fi желісінен ажыратады.

```python
wifi.disconnect()
```

---
### `.ip() -> string | None`
Ағымдағы IP-мекенжайды немесе қосылмаған болса **None** қайтарады.

```python
data = wifi.ip()
print(data)
```

---
### `.status() -> dict`
Қосылу күйінің жиынтығын қайтарады.

**Қайтарады:** **connected**, **ip**, **ssid**, **rssi** және **time** кілттері бар сөздік.

```python
data = wifi.status()
print(data)
```
